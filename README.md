# 03 — SceneLab: өзің басқаратын виртуалды киностудия

SceneLab — камераны, жарықты және кейіпкерлерді басқарып, түсірілімді жоспарлауға арналған браузерлік 3D демо.

## Іске қосу

1. ZIP архивті **толық шығарыңыз**.
2. `index.html` файлын браузерде ашыңыз.
3. Қосымша сервер, Python, Node.js, аккаунт немесе интернет қажет емес. Негізгі файлда барлық стиль, код және 3D кітапхана бар.

WebGL қолдайтын браузер және жұмыс істейтін графикалық жеделдету қажет. Браузер 3D көріністі аша алмаса, бетте түсінікті хабарлама көрсетіледі.

## Дайын мүмкіндіктер

- Авторлық 3D қала ауласы: ғимараттар, терезелер, орындық, үстел, хат және шамдар.
- Екі кейіпкер: орнын, киім түсін және «күту / жүру / қол бұлғау / хатқа қол созу» әрекетін өзгерту.
- Төрт камера үлгісі: жалпы, орта, ірі және жоғарыдан кадр. Бұрыш, арақашықтық, биіктік және объективті қолмен баптау.
- Үш жарық режимі: жылы, суық және нуар. Жарықтың күші мен бағытын өзгерту.
- Үштік композиция торы және қозғалысты тоқтату.
- Жергілікті үлгімен үш кадрдан тұратын жоспар құрастыру. «Түн», «құпия», «жұмбақ» сөздері суық жарықты ұсынады.
- Жоспарға 8 кадрға дейін қосу; атауын және 2–8 секунд аралығындағы ұзақтығын өзгерту; өшіру және ретімен ойнату.
- Жеке кадрды PNG, кадрлар жоспарын PNG, жоба баптауларын JSON ретінде жүктеу және JSON файлын қайта ашу.
- Браузер қолдаса, кадрлар тізбегін дыбыссыз WebM бейнесіне жазу. Жазу батырма басылғанда басталады; бетті ауыстырғанда тоқтайды.
- Баптауларды осы браузерде автоматты сақтау. Сақтау шектелген ортада негізгі редактор жұмысын жалғастырады; JSON экспортын қолданыңыз.

## Қолдану реті

Оқиға идеясын жазыңыз → «Үлгімен 3 кадр жасау» → кадрдың шағын суретін таңдаңыз → камера, жарық пен кейіпкерлерді баптаңыз → өзгертілген көріністі «Кадр қосу» арқылы сақтаңыз → анимацияны ойнатыңыз → нәтижені жүктеңіз.

Тінтуірмен немесе саусақпен алаңды сүйреу камераны бұрады; тінтуір дөңгелегі арақашықтықты өзгертеді. Барлық баптау үшін жеке экрандық басқару да бар. Кадрлар жоспарына жасалған өзгерістер сол құрылғыда сақталады; басқа құрылғыға жіберу үшін JSON файлын экспорттаңыз.

## AI мүмкіндігінің шекарасы

Бұл нұсқа **дайын кадр үлгісін және кілтсөз ережелерін** пайдаланады. Ол оқиға мәтінін еркін түсінетін тілдік модельге қосылмаған. Пайдаланушы кадр атауларын, көріністерді және әрекеттерді өзі өңдейді. AI арқылы сценарий мен диалог ұсыну — кейін қосуға болатын бөлек мүмкіндік.

## Файлдар

| Файл | Мақсаты |
|---|---|
| `index.html` | Толық жұмыс нұсқасы: екі рет басып ашуға болады |
| `src/template.html` | Интерфейс пен CSS бастапқы коды |
| `src/app.js` | Редактор, кадрлар, импорт, экспорт және бейне жазу |
| `src/world.js` | 3D нысандар, кейіпкерлер, камера мен жарық |
| `src/model.js` | Баптауларды тексеру, кадр үлгілері және уақыт шкаласы |
| `src/vendor/` | Three.js 0.180.0 коды және MIT лицензиясы |
| `build.py` | Өзгертілген кодтан интернетсіз толық `index.html` жасау |
| `tests/scenelab.test.mjs` | Логика, нақты 3D геометрия және камера тексерулері |
| `tests/scenelab-ui.test.mjs` | Редактор әрекеттері, бейне жазу күйі және қате өңдеу тексерулері |
| `QORGAU.txt` | Жобаны қорғауға арналған дайын қазақша мәтін |

Кодты өзгерткен соң қайта жинау үшін Python 3 арқылы `python3 build.py` орындаңыз. Ойнау үшін қайта жинау қажет емес.

## Тексеру

Node.js 20+ орнатылған болса:

```bash
node tests/scenelab.test.mjs
node tests/scenelab-ui.test.mjs
```

Алғашқы жеті тексеру кіріс мәндерін шектеуді, JSON файлымен деректерді сақтап ашуды, үш кадр үлгісін, уақыт шкаласын, камера орбитасын және нақты Three.js геометриясын қамтиды. Қосымша жеті тексеру редактор әрекеттерін, жазба аяқталғанша жаңа жазуды шектеуді, кодтау қатесін өңдеуді, сурет пропорциясын сақтауды және 3D алаң ашылмаған кездегі интерфейсті қамтиды.

GPU рендерері, DOM және MediaRecorder сынақта алмастырылған: нақты браузер орналасуы, GPU кескіні, PNG/WebM жүктелуі осы ортада визуалды тексерілген жоқ. WebM қолдауы браузерге байланысты анықталады.
